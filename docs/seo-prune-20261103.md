## How it works and how to revert

- Article markdown in `src/content/articles/` is regenerated from Supabase by `scripts/pull-supabase-articles.mjs`, so none of these changes edit the markdown files. Nothing was deleted.
- `src/data/seo-overrides.json` is the source of truth. `redirects`: the article is no longer built and its URL returns a 301 (lines in `public/_redirects`). `noindex`: the page still builds and stays reachable, gets `<meta name="robots" content="noindex, follow">`, and is left out of `sitemap-0.xml` and `sitemap-images.xml`. `pages`: title, description, callout and heading fixes.
- To revert one URL, delete its JSON entry (and, for a redirect, its two `public/_redirects` lines). `node scripts/check-seo-overrides.mjs [dist]` checks that the JSON, `_redirects` and the build agree.
- Frontmatter `noindex: true` still works too and is also kept out of the sitemap.
- Any page-wide `noindex` now uses `noindex, follow` (it was `noindex, nofollow`), so links on pruned pages still pass through.

## Structured data fixes (`src/layouts/Base.astro`, `src/pages/article/[...id].astro`)

- HowTo `name`: before, the generator prefixed "How to" to non-how-to titles ("How to Construction Accounting Software 2026…"). Now it uses the page title when that starts with "How to", and otherwise the `## How to …` heading the steps came from.
- PodcastEpisode/AudioObject `duration`: before, this was the reading time ("14 min read") on 179 pages. Now it's the real audio length from the RSS feed as ISO 8601 (e.g. `PT20M57S`), or left out when unknown. `sameAs` is the RSS.com episode URL.
- FAQPage answers, HowTo steps and FAQ question names no longer carry raw markdown links or `**`. That affected 670 occurrences.
- `author` stays the Organization. The site doesn't name a real author or host. The transcripts only use the first names "Justine" (host) and "Nicole", in an AI "deep dive" format, so adding a Person would invent one. This needs a decision from the owner.
